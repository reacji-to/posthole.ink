# Product

## Platform

web

## Product Purpose

A tiny public page at posthole.ink that shares the posthole browser extension.

## Capabilities and Constraints

Posthole saves posts from X, LinkedIn, Bluesky, Threads, and Hacker News as structured records with downloaded media and fetched replies. Its local viewer reconstructs source-like cards from data. The extension uses a Node.js native messaging helper and currently supports macOS and Linux installation. GitHub publishing is optional and requires setup.

## Brand Commitments

Keep the existing posthole name and shovel icon. The user wants a tiny, simple website. The source repository is https://github.com/reacji-to/posthole. The domain is registered with Namecheap and the user wants DNS moved to Cloudflare.

## Evidence on Hand

README.md, SCHEMA.md, manifest.json, the extension implementation, and the working local viewer. The public demonstration must use illustrative posts, not the user's browsing archive.
