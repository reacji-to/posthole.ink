posthole

Posthole: a place to store posts.

Keep a local archive of posts you see on social media such as X, LinkedIn, Threads, Bluesky, etc. Search them and view them any way you want.

Give this to your agent to install Posthole

Use https://github.com/reacji-to/posthole/blob/main/README.md to set up posthole.

Or download the extension for Chrome and Helium.

Posts get saved to a folder on your computer.You can search them and view them anytime you want, in any style you want.

Installation & details

For macOS and Linux. You’ll need Node.js 20 or newer.

  1. Download and unzip. Keep the posthole folder somewhere permanent.
  2. Connect the file writer. Open a terminal in that folder and run:
    node scripts/install-host.mjs
    This lets the extension save files to your computer.
  3. Load the extension. Open chrome://extensions (or helium://extensions), turn on Developer mode, click Load unpacked, and choose the dist folder inside posthole.
Open your archive

The default save folder is ~/posthole. To browse it as cards, install Bun, open a terminal in the extension folder, and run:

cd viewer && bun install && bun start

Then visit localhost:4747. You can change the save folder or pause capturing in the extension’s settings.

What gets saved?

Posts the supported sites load while you browse, original images and videos, author avatars, link previews, and reply threads fetched in the background. Posts are stored as JSON alongside their media. Ads are skipped. You can turn off sites, media downloads, or background reply fetching in settings.

Optional GitHub sync can publish your archive and build a searchable database. That requires your own setup; a published archive can be public. Read the details.

Forgettable is for the thought that ruins my mornings: did I lock the door? Is the oven off? Did I switch off the lights?
You can't check from the office, so the doubt follows you all day.
I started from one belief. A reminder only works if it comes by itself. If you have to remember to open a reminder app, you've

Show more

already forgotten.
So the app reacts to what happens around you:
→ you leave or arrive somewhere (a 150 m circle the phone watches, even with the app closed)
→ you drop off or join your home Wi-Fi
→ a set time, or a real alarm that cuts through silent mode
At home it's never just you, so the list can be shared. "Anna locked the door at 08:12" means nobody has to ask anymore.
I designed every screen in Figma and built it with Claude Code. iOS and Android, widgets, Siri, shared households, plus a website with help guides and a privacy policy.
Setting it up takes under a minute: pick the usual suspects (front door, stove, windows), set your home once, done.
The name comes from Neville's Remembrall in Harry Potter. It turned red when he forgot something, but never told him what. This one does.
